# Screenshot shot-list (10 for the submission)

Log in as **demo / accessweave** in Chrome or Edge, keep the default **Light**
theme unless noted, and capture these in order. They tell the product's story:
*understand → sense → control → trust.*

| # | Screen | Why it earns its place |
|---|--------|------------------------|
| 1 | **Home hub** (`/`) | The whole product at a glance — nine tiles, clean icon set, Voice button bottom-right, ⌘K in the nav. |
| 2 | **New task** (`/tasks/new/`) | Five ways in: speak, photograph, paste a URL, type, or use an example. |
| 3 | **Medicine dose card** (task step 2) | The compile result — *Take: one capsule · When: twice daily · With: food.* |
| 4 | **Verbatim warning card** (step 3) | ⭐ The safety promise: "shown exactly as written… never changes a safety instruction." |
| 5 | **Why these steps?** (`/tasks/…/analysis/`) | ⭐ Transparency — barriers with evidence + confidence, task graph, contract checks. |
| 6 | **Look around** (`/look/`) | Live camera with a spoken description visible in the status line. |
| 7 | **Sound Watch** (`/soundwatch/`) | Ideally mid-alert (clap first) so the full-screen visual alert is captured. |
| 8 | **Switch scanning** (any page, **Alt+S**) | ⭐ The highlight ring mid-scan — proves input equity beyond voice. |
| 9 | **Command palette** (**Ctrl+K**, type "look") | The savvy, keyboard-first layer. |
| 10 | **Passport + QR** (`/passports/` → Show QR) | Preferences — never a diagnosis — travelling to another device. |

## Strongly recommended extras

- **Dark theme** of the home hub — shows the palette is properly designed, not
  an inverted afterthought.
- **High contrast** theme — evidence of real accessibility work.
- **Shortcut sheet** (press **?**) — one image that lists every input route.
- **Bill task** — the *"AccessWeave never makes a payment for you"* card.

## Capture tips

- Use a **1280×800** window so text is legible when Devpost scales images down.
- Turn **Focus mode off** for hub shots (it dims the header/footer by design).
- For shot 8, run `window.awScan.setSpeed(4000)` in the console first so the
  highlight sits still long enough to capture.
- For shot 7, the alert lasts ~2.6 s — clap, then capture immediately.
- Crop to the browser viewport; leave the URL bar in for one shot only, to show
  it's a real running app.
